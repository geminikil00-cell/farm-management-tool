# Gemini API Setup Instructions

## Getting Your API Key

1. Visit [Google AI Studio](https://ai.google.dev/)
2. Sign in with your Google account
3. Click "Get API Key" or go to "API Keys" section
4. Create a new API key
5. Copy the API key

## Configuration

1. Open `js/gemini.js`
2. Replace `YOUR_GEMINI_API_KEY` with your actual API key:

```javascript
const GEMINI_API_KEY = 'your-actual-api-key-here';
```

## Usage

- The AI analysis button appears in the "Factors" tab of the Statistical Data page
- Click "🤖 Generate AI Insights" to analyze your farm cycle data
- Results are automatically saved and displayed
- Saved insights appear on the Dashboard and can be viewed anytime

## Features

- Analyzes all cycle performance data
- Identifies key success factors
- Provides actionable recommendations
- Stores analysis results for future reference
- Displays insights on Dashboard
